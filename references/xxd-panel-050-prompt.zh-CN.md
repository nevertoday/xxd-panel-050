# XXD Panel 050｜空气蓝定制旅行矢量场景生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

只处理当前新任务明确提供的这一张源照片。私下锁定主体身份、轮廓、比例、姿态、方向、动作、结构、功能、关系、地方感、生活状态与源图综合色温；至少保留三个源图专属线索，不得借用其他输入、旧输出或样张。

## 审美重构

把源图重构成一张为该主体量身定制的高级极简扁平矢量旅行场景。不要机械描摹，也不要套城市名、地标清单或通用明信片版式。以一个最能承载辨识度与内涵的主体为唯一主视觉，从照片中选择 2–4 个真正能说明环境气质、日常方式、地方感或生活状态的辅助线索，重新组织成有前后层次、适度留白和安静节奏的完整场景。

严格遵循这条因果链：锁定主体、姿态与叙事关系 → 保留三个专属线索 → 选定一个主视觉焦点 → 从源图提炼 2–4 个环境证据 → 按主体气质重组场景而不是套模板 → 用空气蓝平涂矢量语言统一 → 留出安静呼吸 → 让标题与 tagline 成为场景身份的一部分。

## 硬性视觉要求

- 主体可以是城市、建筑、人物、动物、植物、器物、交通工具或自然景观，但必须保持源图的身份、结构、姿态与叙事关系，不得变成同类通用图标。
- 只建立一个明确焦点。辅助元素限 2–4 个，并有源图依据；若确需人物，仅保留 3–6 个小尺度人物，自然融入环境，不另立主角。
- 场景可转化为街道、广场、岸边、庭院、通道、平台、植物场景、室内角落、开放景观或生活片段，但必须由当前源图决定，不得堆叠无关地标或制造过度故事。
- 采用高级极简扁平矢量语言：日系文具感、精品贴纸插画、现代 editorial travel branding；简洁几何形、柔和轮廓、统一线重、平涂色块、克制细节与充足留白。
- 配色从源图综合色温出发，以浅粉蓝、雾蓝、天空蓝或空气感冷调蓝为主，以象牙白、奶油白、浅米色、柔和灰绿与建筑中性色平衡；dusty rose 或 muted blush 只能作微小点色。
- 保持清新、轻盈、安静、优雅、当代和精致。拒绝写实渲染、厚重阴影、水彩或纸张肌理、复杂笔触、渐变、拥挤背景、过多细节、拼贴式地标、明信片罗列与重复构图。

## 文案与语言

服从已经确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。自动文案必须从当前照片的地点、对象名称、主题词、状态、氛围、深意或隐藏关系中提炼，不得默认套城市名。使用一个简短标题与一句克制 tagline；仅在有依据时加入少量坐标式微注释或小字信息。

文字置于真实留白、左上或最适合当前构图的位置，保持 understated、editorial、spacious、premium，并与矢量形状、视线和空间节奏对齐。它应让观众感到文字与画面高度绑定，而不是后贴标题栏。用户准确文案逐字保留；无文字模式不得出现字母、数字、标签或伪文字。

## 模式与验收


拒绝：通用旅游海报、城市名模板、固定地标清单、与源图无关的场景、机械描摹、重复版式、写实或塑料 CG、渐变、纹理、重阴影、拥挤背景、灰脏配色、过量粉色、独立漂浮标题。也拒绝 logo、水印、色卡、UI、设备样机、无依据事实、伪外语与不可读文案。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
